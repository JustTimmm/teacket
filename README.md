# Teacket

Teacket est un projet d'entraînement ayant pour objectif de concevoir une plateforme de **gestion de tickets en ligne**.

L'objectif est de mettre en pratique la conception d'une application web complète, du frontend jusqu'à la base de données, tout en expérimentant une architecture séparant clairement l'interface, l'API et la persistance des données.

## Technologies

| Technologie    | Utilisation     |
|----------------|-----------------|
| **SvelteKit**  | Frontend        |
| **Go**         | Backend         |
| **ConnectRPC** | API             |
| **PostgreSQL** | Base de données |
